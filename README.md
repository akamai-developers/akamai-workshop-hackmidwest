# Build an AI application on Akamai Cloud

A 30-minute Hack Midwest workshop, with an optional 30-minute build session. Learn to call the workshop inference service and use Akamai Cloud for your application's runtime, storage, or database.

## Start here

> ### $300 in free credit for Akamai Cloud
> Sign up with the HackMidwest link: **[http://login.linode.com/signup?promo=akm-dev-hack-mid-300-100826-K277](http://login.linode.com/signup?promo=akm-dev-hack-mid-300-100826-K277)**

1. **[Set up your laptop](docs/00_prework.md)** before the session.
2. **[Follow the workshop](docs/workshop.md)** for your first model request and a document retrieval example.
3. **[Build your project](docs/build.md)** using the components you need during the hackathon.

The inference notebooks require a team API key from the organizers. Cloud labs also require an activated Akamai Cloud account and create billable resources. Review [costs and cleanup](docs/costs.md) before deploying.
